\section{Conclusion}
This paper presents \sysname, which addresses heterogeneous function demands
through complementary swarming routing and monotonic scale-up scheduling. At
the cluster level, \sysname co-locates complementary functions to improve server
utilization while narrowing each node's function set to increase instance reuse.
At the node level, it aligns request ordering with in-place pod scaling, adapting
allocations to request demands and reducing cold starts without over-provisioning.
Our evaluation shows higher resource utilization and throughput than the
baselines, with negligible overhead and scalable performance.
