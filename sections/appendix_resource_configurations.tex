\section{Reference Resource Configurations}
\label{app:resource-configurations}

Table~\ref{tab:supp-resource-config} reports the resource configurations used
in the system experiments. These configurations are conservative empirical
values selected according to the observed end-to-end runtime behavior of each
benchmark, including task execution, runtime state, and input/output processing.
They are applied consistently to COSMOS and all baselines. The allocation ratio
is the configured CPU-to-memory ratio used to derive CPU allocations from the
evaluated memory-demand distributions.
